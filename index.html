Cómo Compilar esta App como APK en GitHub + Plataformas

Flujo automatizado con Capacitor y GitHub Actions sin instalar Android Studio

1. ¿A qué plataformas de canciones puedes conectarla?

  • Archivos .MID / .MIDI (Integrado): Es el estándar universal. Cualquier canción descargada de MuseScore, BitMidi, FreeMidi o GitHub se puede cargar con el botón .MIDI.
  • TheSession.org API (Integrado): Base de datos JSON abierta y sin clave API con más de 40.000 melodías en notación ABC que esta app convierte al instante.
  • Repositorio JSON propio en GitHub: Puedes alojar una carpeta /songs/*.mid en tu propio repositorio y listarlas automáticamente.

2. Permiso de Micrófono en Android (`AndroidManifest.xml`)

Para que la detección de frecuencia funcione en el APK instalado en tu móvil, añade este permiso en android/app/src/main/AndroidManifest.xml:

<uses-permission android:name="android.permission.RECORD_AUDIO" />
<uses-permission android:name="android.permission.MODIFY_AUDIO_SETTINGS" />

3. GitHub Action (`.github/workflows/build-apk.yml`)

name: Generar APK Android
on: [push, workflow_dispatch]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 20 }
      - uses: actions/setup-java@v4
        with: { distribution: 'temurin', java-version: '17' }
      - name: Empaquetar Web en Android con Capacitor
        run: |
          npm init -y
          npm install @capacitor/core @capacitor/cli @capacitor/android
          npx cap init PianoSense com.pianosense.app --web-dir .
          npx cap add android
          npx cap sync android
          cd android && chmod +x gradlew && ./gradlew assembleDebug
      - name: Subir APK listo para instalar
        uses: actions/upload-artifact@v4
        with:
          name: PianoSense-debug-apk
          path: android/app/build/outputs/apk/debug/app-debug.apk
